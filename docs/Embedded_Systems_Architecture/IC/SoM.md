# 1. SoM là gì?

**System-on-Module (SoM / SOM)**: là một module ở cấp độ board nhỏ gọn, tích hợp một SoC cùng các thành phần hỗ trợ như memory, power management, wireless interfaces và các I/O interfaces, tạo thành một computing system hoàn chỉnh trên một module.
